# Kシステム｜芝上り3F距離補正研究・最終総括
作成：2026年10月22日
対象：2015年～2026年6月28日

## 1. 今回の主題と到達点

全国の芝2勝クラスを基準に、
上り3Fの距離補正を研究し、
全クラス共通の仕様を決定した。

芝2勝クラスは比較の基準にしやすく、
距離間の能力・展開差を研究する基盤となる。

## 2. 採用した距離補正

2000m基準。単位は秒。

| 距離 | 加算補正値 |
|---|---:|
| 1200m | +1.410 |
| 1400m | +1.075 |
| 1600m | +0.740 |
| 1800m | +0.370 |
| 2000m | 0.000 |
| 2200m | -0.170 |
| 2400～3600m | -0.340（一律） |

1400m・1800m・2200mの追加αは0。

すべてのクラスに同じ補正値を適用する。
新馬・未勝利・1勝・2勝・3勝・OP・重賞を含む。

これはクラス間の能力差を消すものではない。

表にない1200～2400m間の距離については、
必要時に適用ルールを別途定める。

## 3. 2400m以上を固定した理由

長距離では、勝ち時計を犠牲にして
道中の速度負荷を抑えれば、
非常に速い上り3Fを使うレースがある。

距離延長に合わせて補正を機械的に増やすと、
距離・競馬場・展開の特徴を消してしまう。

そのため、2400m以上は-0.340秒に固定する。

これは2400m以遠の実際の距離負荷が
ゼロと実証されたことを意味しない。

## 4. 検証データ

芝2勝クラスのレース数。

1200m：519R
1400m：317R
1600m：422R
1800m：454R
2000m：498R
2200m：123R
2400m：168R
2600m：100R

計算条件：
・全馬場状態
・有効完走馬の後方1/8除外
・馬場差補正
・RPCI別比較

馬場差補正：
実上り3F平均 - 馬場差×600÷距離

2400m・2勝168R、
2600m・2勝100Rは既存研究と照合。
不一致0R。

参考として、2400mは
3勝90R、非重賞OP13R。

2600mは3勝0R、非重賞OP28R。

競馬場構成の差を距離差と混同しない。

## 5. 最重要の研究考察（仮説）

【1600m未満】

速度負荷が強い反面、
道中の流れを緩めると負荷も大きく変わる。

そのため、上り3Fの飽和帯が
安定して形成されにくい可能性がある。

【1600m・2000m】

速度と持続力の双方が要求され、
馬の能力をごまかしにくい距離ではないか。

【長距離】

勝ち時計を犠牲にして道中の負荷を抑えれば、
速い上り3Fを使うことができる。

そのため、上り3Fの飽和帯を
一律に定義しにくい可能性がある。

【能力分析の中心仮説】

能力分析の精度は、

1600～2000mを主戦場にする馬
    ↓
1600m未満を主戦場にする馬
    ↓
長距離を主戦場にする馬

の順になるのではないか。

これは着順の紛れや波乱ではなく、
負荷を受けた際に馬の能力が
どれだけ明確に表れるかという意味である。

この精度順位は研究仮説であり、
今後の分布図で検証する。

## 6. 採用・不採用・保留

【採用】
・芝距離補正の統一仕様
・全クラス共通適用
・2400～3600mの補正値固定

【不採用】
・2400m以降を-0.170秒/200mで機械的に延長
・根拠のない減衰率による外挿

【保留】
・能力分析の距離別精度順位の実証
・飽和帯の厳密な判断
・表にない距離の補正方法

## 7. 次の研究への引継ぎ

次は、全国共通補正を維持したまま
競馬場別分布図の研究へ進む。

RPCI・上り3F・道中速度負荷・
コーナーRなどを使い、コース特性を分析する。

決定事項と研究仮説を混同しない。

基本思想：
「必然を追求する」

補正によって競馬場・距離・展開の
本来の特徴を消さない。
