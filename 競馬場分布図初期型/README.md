# Kシステム｜競馬場分布図初期型

**研究引継ぎ・暫定決定事項（2026-10-21）**

> **注意：本資料は結論・検証経緯・次の課題をまとめた引継ぎ資料です。** 生データ・検証CSV（80～116等）の原本は Google Drive の `keiba_data/競馬場分布図研究/芝_距離補正研究` に保存されたままです。原本を変更・移動・削除しないこと。数値は暫定採用であり、純粋な距離負荷の因果的分離が証明されたわけではありません。

## 1. 研究目的と思想

Kシステムは競馬場・距離・Q（RPCI）ごとに異なるレースの特性を分布図として捉える。芝の異なる距離で「上り3F」を比較可能にするために、距離由来と考えられる差の基準を設定する。目的は全コースを同じ平均値に揃えることではない。**競馬場の固有性、ペースの特徴、スピード負荷は分布図の情報として残す**。見えない範囲を予測値で埋めない。「根拠に基づく必然」を重視する。

### 研究母集団

- JRA全国の芝2勝クラス、2015～2026年、**1,607レース**、`race_id`重複0。
- 1200m **519R**、1600m **422R**、2000m **498R**、2400m **168R**。
- RPCIの観測全範囲 **37.9～67.5**。全RPCI帯を使い、実績がない領域は欠測・保留とする。
- 上り3Fは馬の実測上りを基にした上位馬中心の平均（後方1/8除外、馬場差補正）であり、先頭馬のレースラップそのものではない。前半平均3F換算はレースのラップから求める。両者を同一種類の時計として扱わない。
- Q区分とRPCIの対応に関する既存ルールを尊重する。Qは今後の説明軸。補正値をQに依存させることは**現時点では採用しない**。

## 2. 現在の暫定補正値（2000m基準）

| 距離 | 補正上り3Fに加算する秒数 | 判定 |
|---:|---:|---|
| 1200m | **+1.41秒** | 暫定採用 |
| 1600m | **+0.74秒** | 暫定採用 |
| 2000m | **0.00秒** | 基準 |
| 2400m | **−0.34秒** | 暫定採用 |

**適用例**：1200mの馬場差補正後上り3Fが34.00秒であれば、2000m換算値は35.41秒。未検証距離への補間・外挿は禁止。

### どう得たか

高RPCI側で比較的安定する距離間の実測上り差について、帯幅・必要サンプル数・高RPCI領域の取り方を変えた**54条件**を検証。

| 距離間 | 暫定区間差 | 両距離5R以上の条件での中央値 | 条件感度の範囲 |
|---|---:|---:|---:|
| 1200→1600m | +0.67秒 | +0.6705秒 | +0.5965～+0.7366秒 |
| 1600→2000m | +0.74秒 | +0.7448秒 | +0.6910～+0.7715秒 |
| 2000→2400m | +0.34秒 | +0.3396秒 | +0.2840～+0.4020秒 |

区間差を2000m基準に連結した（1200m: 0.67+0.74=1.41、1600m: 0.74、2400m: −0.34）。ただし、3区間の**共通RPCI実測範囲は同一でない**ので、この加算は暫定的な実務尺度であり、厳密に同じ条件下で測った距離負荷の加法性を証明するものではない。

## 3. スピード負荷とRPCI

低RPCI側では距離間の上り差が拡大する傾向を観測。今回の距離補正は、その拡大分を積極的に打ち消さない。

- 1200→1600m: RPCI49付近の低側の上り差0.8316秒、高側0.6878秒、差+0.1438秒。ただし開催年再抽出95%参考区間は−0.0336～+0.3094秒で不確実。
- 1600→2000m: RPCI53を境界候補とすると低側0.9581秒、高側0.7394秒、差+0.2187秒。年再抽出95%参考区間+0.1251～+0.3557秒。境界を51～55へ変更しても増分+0.2001～+0.2255秒。
- RPCIをそろえても前半実時計が異なり、前半速度をさらにそろえると結果が変わる。低RPCI側の上乗せを**純粋なスピード負荷と断定しない**。49や53を物理的な閾値として正式採用しない。
- 2000→2400mでは低側と高側の差が比較的小さく、距離間差は概ね0.3秒付近で観測された。

**暫定運用**：スピード負荷は補正しない。Q・RPCIとの関係を競馬場分布図の特徴として残す。将来数値化できても、それを補正に使うかどうかは別の判断。

## 4. 飽和帯：距離負荷候補の確認材料

以前の研究思想：高RPCI側で、前半をさらに緩めても上りが改善しなくなる「飽和帯」には、距離による基本的な差が現れる可能性がある。

**重要な合意**：飽和帯の検証は、高RPCI側の距離負荷候補を**確認する作業**であり、飽和が検出できなかった距離の暫定値を一律に取り消すための新条件ではない。

| 距離 | 今回の前半3F換算飽和候補 | 判定・注意 |
|---|---|---|
| 1200m | 34.75～35.50秒付近（0.25秒帯で61R） | 候補あり。候補よりさらに遅い前半の標本は乏しい |
| 1600m | 37.0秒付近 | 横ばいが見えるが、その先で改善し、未確定（少数標本） |
| 2000m | 38.0～39.0秒（66R） | 候補あり |
| 2400m | 38.5～39.5秒（30R） | 候補あり・標本少 |

2000→2400mの双方飽和候補が存在する同RPCI帯で、上り差はRPCI幅1.0の1帯で**+0.301675秒**、幅2.0の3帯で**+0.281622秒**。高RPCI側54条件の約+0.34秒と方向・規模が概ね整合。ただし、飽和帯だからスピード負荷ゼロとは証明できていない。

**元の過去の飽和候補**（参考）: 1200m 35.4秒、1600m 37.0秒、2000m 38.3秒、2400m 38.1秒前後。過去と今回の集計条件の違い（例：良・稍重の限定）は混同しない。

## 5. 引継ぎ時の状態区分

### 暫定決定
- 2000m換算の加算値：1200 **+1.41**／1600 **+0.74**／2000 **0**／2400 **−0.34**秒。
- 芝2勝クラスの全RPCI実測を基盤とする。
- 距離補正以外に、特定競馬場だけを平均へ寄せる補正は加えない。
- スピード負荷はQの特徴として残し、現段階では別途補正しない。
- 飽和帯の検証は確認材料。高側上位1/3と1/2は飽和帯そのものと同義ではない。

### 未解決（研究継続）
1. 補正を**実際の競馬場×距離×Qの分布図へ適用**し、特徴がどう残るかを可視化・評価する。
2. 1200/1600/2000/2400m以外の距離の補正方法（安易な補間は不可）。
3. 芝2勝クラス以外の階級への適用の可否。
4. 異なる共通RPCI範囲から得た区間差を連結した時の残余誤差、競馬場構成・前半速度の残留影響。
5. 1600mの飽和帯開始位置などは保留。必要性が出た時に重点検証。

### 旧値・別目的の参考値（**採用値と混同しない**）
- Q＋前半速度をそろえた比較由来の以前の候補：2000m基準、1200m **+1.0866**、1600m **+0.6229**、2000m **0**、2400m **−0.2554**秒。条件・研究目的の違いがあるため**現行の距離補正には使わない**。
- 全距離の平均を強制的に一致させる調整、未観測RPCI帯への外挿、特定競馬場の特徴を削る補正は行わない。
